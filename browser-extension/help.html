Connect your signed-in AI websites

This companion extension connects Chrome's normal chat interfaces to your local Antigravity Studio app. It is independent of the six website providers.

One-time installation

  1. Open chrome://extensions in Chrome and enable Developer mode.
  2. Choose Load unpacked and select the browser-extension folder supplied with Antigravity Studio.
  3. Open Antigravity Studio and start its Browser Connector on port 4319.
  4. Open this extension's popup and choose Connect to app. Review and approve the pairing request in the desktop app.
  5. Use Open / sign in for each service you want to use. Complete sign-in or browser verification yourself. Return to the popup and refresh its status.
  6. Select that service's web alias in the app and send a message.

What happens to your tabs

The extension checks supported open tabs for a usable chat composer. Each app request opens a fresh task tab in the same Chrome profile, so it can use that profile's existing sign-in. It submits only the conversation supplied by your local app and reads the newly rendered assistant response. Existing conversations and drafts are not edited. Successful task tabs close; failed tabs remain for inspection. Cancelling in the app stops and closes only its task tab.

Privacy and access

No cookies permission is requested. Cookies, passwords, session tokens, browser storage, and private website APIs are not read or exported. Website sessions remain in Chrome. The only saved credential is the separate local-app pairing token, restricted to trusted extension contexts. Prompts are sent to the selected website and its result returns to 127.0.0.1:4319. Only the six named site hosts and that local port are permitted.

Model and tool limits

The aliases claude-web, chatgpt-web, deepseek-web, qwen-web, zai-web, and gemini-web select a website. They do not force a particular model, plan, reasoning mode, or account entitlement. Those stay under your control on the website. Tool calls are requested as structured text; malformed or undeclared calls are rejected. The desktop app applies its own tool checks and approvals. Images and uploads are not supported by this connector.

Troubleshooting

If a service says sign-in required, open it normally and complete its sign-in yourself. Verification challenges are never bypassed. If a site is already signed in but its composer, send button, or completion state is not recognized, its interface may have changed. Use its direct API or update the adapter; the connector will report an error rather than return old or incomplete text as success. Leave task tabs alone while they run; interacting with one stops its automation.

Disconnect from the popup to stop local requests and remove this extension's pairing token. Revoke the pairing in the desktop app to invalidate access there.
